# Trip.com Discount Codes – GitHub Pages

Independent SEO-friendly static site for Trip.com coupons and travel offers, linking to **TheSmart.Deals**.

- Source: https://www.thesmart.deals/trip-com-discount-codes
- Trip.com new-user affiliate link: https://www.trip.com/t/Bvvzl3BiIS2
- Suggested repository: `trip-com`
- Suggested GitHub Pages URL: https://voucher-insider.github.io/trip-com/

## Deploy
1. Create a public repository named `trip-com` under `voucher-insider` (or change the `base` URLs in HTML, robots.txt and sitemap.xml for your own username).
2. Upload all files to the **repository root**.
3. Enable **Settings → Pages → Deploy from a branch → main / (root)**.

## Contents
Responsive HTML pages, CSS, `robots.txt`, `sitemap.xml`, `.nojekyll`, FAQ structured data, social metadata and affiliate disclosure.

## Editorial note
The **Verified Offer** label is an editorial presentation label only; it is not a third-party certification. Confirm discounts and eligibility with Trip.com. The attached source mentions higher seasonal discounts, which are not guaranteed.
